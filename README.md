Create · Edit · Inspire
Snipzo एक मोबाइल वीडियो-एडिटिंग ऐप का इंटरैक्टिव UI प्रोटोटाइप है, जो शुद्ध HTML, CSS और JavaScript में बनाया गया है। इसमें कोई असली वीडियो-प्रोसेसिंग इंजन नहीं है — यह सिर्फ़ ऐप के डिज़ाइन और स्क्रीन-फ़्लो को दिखाने के लिए है।
स्क्रीन्स
इस प्रोटोटाइप में निम्नलिखित स्क्रीन शामिल हैं:
Splash — ऐप का शुरुआती लोगो स्क्रीन
Login — Google, Gmail या Email से साइन-इन
Home — क्विक टूल्स, हाल के प्रोजेक्ट्स
Editor — वीडियो प्रीव्यू, टाइमलाइन, टेक्स्ट/ऑडियो ट्रैक
Tools — ट्रिम, इफ़ेक्ट्स, फ़िल्टर्स जैसे सभी एडिटिंग टूल्स
Templates — रेडीमेड वीडियो टेम्पलेट्स
Export — रिज़ॉल्यूशन, फ़्रेम रेट, फ़ॉर्मेट सेटिंग्स
Projects — सभी सेव किए गए प्रोजेक्ट्स की लिस्ट
Profile — प्रोफाइल फोटो, नाम एडिट, ऐप लैंग्वेज जैसी सेटिंग्स
इस्तेमाल कैसे करें
ब्राउज़र में सीधे खोलें
index.html फ़ाइल को किसी भी ब्राउज़र (Chrome, Firefox आदि) में खोल दें। ऊपर दिए गए नेविगेशन बटन से अलग-अलग स्क्रीन के बीच जा सकते हैं।
GitHub Pages पर होस्ट करें
GitHub पर एक नई public repository बनाएं
index.html फ़ाइल उसमें अपलोड करें
Settings → Pages में जाकर branch चुनें और Save करें
कुछ मिनट में लाइव लिंक मिल जाएगा
Spck Editor में चलाएं
Spck Editor ऐप खोलकर नया प्रोजेक्ट बनाएं
index.html में यह कोड पेस्ट करें
सेव करके ऊपर दिए Run/Preview बटन से देखें
तकनीक
HTML5
CSS3 (Flexbox, Grid, CSS Variables)
Vanilla JavaScript (कोई फ्रेमवर्क या लाइब्रेरी नहीं)
फ़ाइल संरचना
कोड।  index.html   → पूरा ऐप (HTML + CSS + JS एक ही फ़ाइल में)
README.md    → यह दस्तावेज़
नोट
यह एक स्टैटिक डिज़ाइन प्रोटोटाइप है। असली वीडियो ट्रिमिंग, इफ़ेक्ट्स, एक्सपोर्ट प्रोसेसिंग, और अकाउंट सिस्टम जैसी सुविधाओं के लिए बैकएंड और एक वास्तविक वीडियो-एडिटिंग इंजन अलग से बनाना होगा।
